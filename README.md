# 🏠 Rent Calculator

A simple **Python-based Rent Calculator** that helps calculate the total monthly living expenses and the amount each person needs to contribute when sharing a house or accommodation.
#project website link: https://sazuu8uu5-rent-calculator.streamlit.app/

## 📌 Project Overview

Managing shared accommodation expenses can sometimes be difficult. This project provides a simple solution by taking the major monthly expenses as input and calculating the total expense as well as the **rent payable by each person**.

The calculator considers:

* House Rent
* Food Expenses
* Electricity Bill
* Number of People Sharing the Accommodation

The program then calculates the total monthly expense and divides it equally among the people.

## 🚀 Features

* Calculate total monthly expenses
* Calculate per-person rent/contribution
* Accept user input dynamically

## 🧮 Calculation Formula

### Total Monthly Expense

```text
Total Expense = House Rent + Food Expense + Electricity Bill
```

### Per Person Expense

```text
Per Person Expense = Total Expense / Number of People
```

## 💻 Example

### Input

```text
Enter House Rent: 12000
Enter Food Expenses: 6000
Enter Electricity Bill: 2000
Enter Number of People: 4
```

